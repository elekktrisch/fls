# CPD duplication ratchet baseline — total duplicated tokens (J-5 T-11).
#
# The `cpdRatchet` task (build.gradle.kts) sums the `tokens` attribute across
# every <duplication> block in build/reports/cpd/cpdCheck.xml and FAILS the
# build iff that total exceeds the number below. So existing duplication debt
# passes; only NEW duplication reds CI.
#
# Lower is better. When duplication drops, cpdRatchet prints the new (lower)
# number — commit it here to lock the gain (the ratchet only tightens).
