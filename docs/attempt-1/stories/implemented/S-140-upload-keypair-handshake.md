## Context

Vision C28 specifies an "on-the-fly generated public-key for the encryption" per upload. This is the server side of that handshake: generate a fresh keypair, retain the private key encrypted-at-rest until ingest consumes it (S-141), surface the public key for the user to feed to the JAR (S-139). Per-upload (not per-user, not global): each ingest stands on a fresh keypair so the blast radius of a leaked private key is bounded to a single upload's bundle.

## Cross-story contracts

- **S-141 owns** the `awaiting_upload → consumed / failed` transitions and the `t_migration_run` parent row. The `MigrationUploadState` enum is defined here once; S-141 imports it.
- **S-141 pickup note** — consider re-refining to adopt Tink's `StreamingAead` (`AES256_GCM_HKDF_4KB`) for the bundle decrypt; same security guarantee as raw `Cipher`+`CipherInputStream`, no JDK deferred-tag footgun. Reuses the same `KeysetHandle` bean.
- **S-141 error taxonomy hand-off** — an upload arriving at `expires_at + epsilon` returns the distinct code `BUNDLE_HANDSHAKE_EXPIRED` (separate from decrypt failure codes).
- **S-139 hand-off** — `MigrateHandshakePageComponent#JAR_DOWNLOAD_PLACEHOLDER_HREF` is the swap point for the JAR release URL.

## Deferred follow-ups

- **Terminal-row sweep** — deleting `superseded` / `expired` / `failed` rows past N days is out of scope; file an ops-housekeeping stub at finalize.
- **Per-endpoint rate-limit** — RSA-4096 keygen is a CPU DoS amplifier; deferred to **S-041** (rate-limit infra). Caddy per-IP cap is the interim defence.
- **SPA email-verified guard + `/verify-email-pending` page** — design notes called for a SPA-side redirect on unverified email; the destination page doesn't exist yet, so today the server `@PreAuthorize` is the load-bearing gate (403 on unverified). File a follow-up story for the SPA redirect + destination page.
- **Concurrent-handshake race / master-keyset-across-restart / fail-fast-on-empty-keyset ITs** — refinement test plan named these explicitly; only happy / supersede / 401 / 403 / expiry-idempotency landed. The race-loser path at `MigrationHandshakeService#insertFreshOrSupersede` is exercised structurally (partial UNIQUE) but not via `CompletableFuture.allOf`. File a follow-up for the IT hardening.
- **SPA store swap to the generated OpenAPI client** — `migration-handshake.service.ts` (generated by orval) now exists; the store still consumes the hand-rolled `MigrateHandshakeService`. Swap on next touch.
- **Operator runbook for Tink keyset rotation + ALPENFLIGHT_MIGRATION_MASTER_KEYSET provisioning** — fail-fast is wired (`MigrationCryptoConfig`); the runbook is plan-noted but not yet authored.
